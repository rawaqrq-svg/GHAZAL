# GHAZAL POS - تطبيق سطح المكتب لنظام Windows 10/11 (Desktop App)

تطبيق كاشير مستقل ومبني بإطار **Electron** يتصل مباشرة بالسيرفر المركزي لنظام **غزل (GHAZAL Cosmetics & More)**.

---

## 1. المميزات
* نافذة كاشير مستقلة كاملة الشاشة مع دعم وضع ملء الشاشة (`F11`).
* **الطباعة الصامتة المباشرة**: طباعة الإيصالات الحرارية (80 مم) على الطابعة الافتراضية دون إظهار نافذة المتصفح.
* **فتح درج النقدية التلقائي**: إرسال نبضة الفتح لدرج الكاشير عند إتمام العمليات النقدية.
* **اختصارات لوحة المفاتيح السريعة**:
  * `F2`: التركيز على شريط البحث ومسح الباركود.
  * `F4`: الانتقال الفوري لشاشة الدفع.
  * `F6`: تعليق السلة الحالية.
  * `F11`: التبديل بين وضع ملء الشاشة والنافذة العادية.
* **الأمان والعزل**: لا يحتوي التطبيق على أي بيانات دخول سرية لقاعدة البيانات، بل يتصل عبر قنوات مشفرة مع السيرفر المركزي.

---

## 2. التشغيل في بيئة التطوير (Development)

1. الانتقال إلى مجلد `desktop`:
   ```bash
   cd desktop
   ```
2. تثبيت الاعتماديات:
   ```bash
   pnpm install
   ```
3. تشغيل التطبيق:
   ```bash
   pnpm start
   ```

---

## 3. بناء مثبت Windows الرسمي (.exe Installer)

لتوليد ملف التثبيت المعتمد لأجهزة الكاشير:
```bash
pnpm dist
```
سيتم إنشاء ملف المثبت داخل مجلد `desktop/release/` باسم:
`GHAZAL POS Setup 1.0.0.exe`
ويتضمن:
* اختصار رسمي على سطح المكتب وقائمة Start بأيقونة غزل.
* معالج تثبيت باللغة العربية (NSIS).
* إعدادات التكوين وحفظ مسار السيرفر المركزي.
